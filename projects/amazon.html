Data Preprocessing

Cleaning & Feature Engineering

Handling a 117GB sparse dataset required careful decisions on imputation, filtering, and feature construction before any modeling could occur.

Missing Values
Exclusion Strategy
Features with non-integral values such as review_body were excluded such that they provide no predictive value. Additionally, only U.S. marketplace reviews were retained for English-language consistency. Missing rate was < 0.02%.
Class Imbalance
Resampling & Weighting
5-star reviews dominate the label distribution. Class weighting and resampling techniques were applied using Spark where imbalance distorted model performance, particularly for 1–3 star predictions.

Model 2: Random Forest with PCA + K-Means Clustering

K-Means clustering was used to identify behavioral groupings among reviewers. PCA was then applied to reduce dimensionality and evaluate how feature compression affected cluster separation.

01
Standard Features

The model exhibits a strong upward prediction bias, with most observations classified as 5-star ratings. While it correctly identifies many true 5-star reviews, ratings 1–4 are frequently misclassified as 5, especially for 3- and 4-star reviews. This pattern suggests that the model captures high-rating behavior but struggles to distinguish among lower-rating classes.

02
PCA

PCA features lead to a complete collapse in class discrimination, with the model assigning every observation to the 5-star class. As a result, ratings 1–4 have zero correct predictions, while only true 5-star reviews are classified correctly. This suggests that the PCA-transformed representation does not retain sufficient predictive information for the Random Forest to distinguish between rating classes.

Conclusion

Results & Observations

The model performs well on 5-star reviews but struggles with lower-rated classes due to class imbalance, presenting a structural challenge requiring future mitigation.
